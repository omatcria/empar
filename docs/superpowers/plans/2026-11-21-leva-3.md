# Leva 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar reset de dados, alertas do MEI, logos de bancos/bandeiras com cor automática, Select padronizado, módulo isolado de dívidas e lista de desejos com monitoramento diário de preço.

**Architecture:** Banco primeiro (migrações + tipos), depois uma fiação compartilhada feita pelo controlador (rotas, navegação, stubs, stores-esqueleto) para que seis frentes paralelas editem só arquivos próprios. Regras de negócio em engines puras testadas (Vitest); leitura de produto e lógica de preço em `supabase/functions/_shared/` (TS puro) reaproveitada pelo app e pelas Edge Functions.

**Tech Stack:** Vite 8, React 19, TS 6, Tailwind v4, Zustand 5, Recharts 3, date-fns 4, Vitest 4 + Testing Library (jsdom), Supabase (Postgres, RLS, Edge Functions Deno, pg_cron, pg_net, Vault), agent-browser 0.38.

**Spec:** `docs/superpowers/specs/2026-11-21-leva-3-design.md`

## Global Constraints

- Dinheiro sempre em centavos inteiros (`Cents` de `@/lib/money`); formatação com `formatBRL`.
- Ícones só de `@/components/icons` (adicionar mapeamento Tabler lá); nunca `lucide-react`.
- Classes de texto: `text-app-fg` / `text-app-fg2` / `text-app-muted`; superfícies `bg-app-surface`, `bg-app-surface-2`, borda `border-app-border`, cantos `rounded-xl`.
- Toda tabela nova: `workspace_id` + `user_id`, RLS `is_member(workspace_id)` no SELECT e `has_write(workspace_id)` em INSERT/UPDATE/DELETE, GRANT para `authenticated`.
- Inserts do app usam `ownerCols()` (exportado de `src/store/owner.ts` na Task 2).
- Limite MEI padrão: `8100000` centavos (R$ 81.000,00). Faixas: `<70` ok · `70–<90` atencao · `90–<100` critico · `100–120` excedido · `>120` desenquadrado.
- Alerta de preço: queda **≥ 5%** vs. último preço, ou cruzar o preço-alvo.
- achar.promo: `https://www.achar.promo/` + URL sem `http(s)://` e sem um `www.` inicial; caminho/query/hash preservados byte a byte.
- Dívidas nunca criam `transactions` nem entram em engine de saldo/dashboard/relatórios/notificações.
- Textos de interface em português do Brasil.
- Frentes paralelas: cada tarefa só edita os arquivos listados nela; commit com `git add <caminhos explícitos>` (nunca `git add -A`); se `index.lock` existir, esperar e repetir.
- Acesso ao banco/Edge Functions: script `scripts/supabase/sbq.sh` (criado na Task 1; lê o token do `.mcp.json`, nunca imprime).
