- Funções de engine recebem "hoje" por parâmetro; nada de `new Date()` dentro de `src/engine/`.
- Ícones só de `@/components/icons` (mapeamento Tabler lá); nunca `lucide-react`.
- Classes: `text-app-fg`/`text-app-fg2`/`text-app-muted`, `bg-app-surface`/`bg-app-surface-2`, `border-app-border`, `rounded-xl`.
- Textos de interface em português do Brasil, exatamente como nas tarefas.
- Dívidas nunca criam `transactions` nem entram em saldo, previsão, relatórios ou notificações.
- Banco: `scripts/supabase/sbq.sh` (SQL) e `scripts/supabase/gen-types.sh` (tipos); token só via `.mcp.json`, nunca impresso nem commitado.
- Tarefas paralelas: editar só os arquivos listados na tarefa; ícone novo = Edit pontual em `src/components/icons.ts` (1 linha no import, 1 no export) relendo o arquivo antes; `git add <caminhos explícitos>` (nunca `-A`, `.`, `-a`); `index.lock` → esperar e repetir; não usar `git stash/reset/checkout --`.
